# UI / UX / performance review (phase 6, 2026-10-22)

One agent (Sonnet 5.5, high effort) went through the dev build of `big-update` with a copy of the user's library
(2,996 songs, not signed in to any service). Full report (French) handed to the user in the chat. Overall 6.5 / 10:
daily user 7, lover of practical interfaces 5.5. Idle CPU ~1 % of a core, 3,000-row list smooth even in debug.

## Fixed after the review

| Finding | Fix |
|---|---|
| `confirm()` is async under Tauri's dialog plugin (a Promise, always truthy): delete playlist, remove from library, forget history, sign out ran without waiting | App's own dialogs (`shared/ui/Ask.tsx`: `ask`, `askText`), `prompt()` gone too; a test fails on any `confirm(` / `prompt(` / `alert(` |
| Dialogs: no initial focus, Tab escaped, focus lost on close | `Dialog` focuses the first field or default action, keeps Tab inside, gives focus back |
| Space played / paused even on a keyboard-focused button or switch | Space presses controls reached by keyboard (`:focus-visible`) and anything in a dialog |
| Unmute jumped to 100 % when the volume was at 0 without the mute button | Back to the last audible volume, 50 % when none is known (one `toggleMute` in the store) |
| `save_session` (whole queue) on every volume tick while dragging | Volume / shuffle / repeat saves wait 0.6 s |
| Progress loop at the screen's rate (222 calls a second at 222 Hz) | About 60-80 ticks a second at most |
| A refused video could sit on YouTube's "Video unavailable" card with no error event | 10 s watchdog: watch page, then another upload, then the next song |
| Fresh WebView2 profile in the EU: YouTube's cookie dialog (hidden by the watch-page script) held playback silently | Detected and reported with a clear message, the song skipped; never answered for the user |
| No backup of the library (after the 2026-10-21 incident) | Copy before any migration (`library-before-v<N>.db`) and a daily copy (`library-daily.db`) |
| `lock().unwrap()` on the library: one panic locked every later command out | `AppState::lib()` recovers a poisoned lock |
| Sync Mode key: Argon2id at OWASP's minimum (19 MiB, 2 passes), 8-character passwords | 64 MiB, 3 passes, 10 characters |
| Release builds kept the browser's keys (F5 reload cut the music, Ctrl+F, Ctrl+P, F12) | Turned off in release (`shield::browser_keys_off`); page shortcuts and copy / paste unaffected |
| No mouse back / forward buttons | Side buttons go back / forward |
| Now Playing at 960 x 600: volume bar under Up next | Bar narrows |
| Spotify connect wizard squeezed Settings into one word per line | Sections go in rows above the page when there is no room |
| Shield text spoke of an API key (gone since 2026-10-16) | Account restriction and breakage instead |
| "2 996 jouable en entier" (same text for one and many) | Real singular / plural |
| "Reset appearance" without a question | Asks first |
| `stop_with` (startup error box) built on Windows only | Message on stderr elsewhere |

Checked and not a bug in the app: YouTube's overlay "visible while paused" and the "stuck" videos came from the review's
environment (debug flag replacing the app's autoplay flag, fresh profile with YouTube's cookie dialog); a paused video
shows no overlay.

## Still open (from the review, not done here)

- Mini player always shown for YouTube (terms: the player must stay visible) covers content: reserve its space or
  dock it in the sidebar; keyboard move / resize.
- Lists: keyboard navigation (one tab stop, arrows, Enter), multi-select, drag and drop, reorderable queue.
- Text size (12 px and under is ~60 % of the text), a text-size setting apart from zoom; `user-select: none` everywhere.
- Settings layout: General / Playback / Appearance instead of playback settings in Appearance and daily ones in
  Advanced; Hi-Fi leftovers (tuner, knob, vinyl, Hi-Fi font) to drop or tuck away.
- Library: artists and albums are YouTube channel names ("- Topic", several artists in one), album / artist chips count
  songs, no sort by column header, 3 px slider hit areas.
- Defaults to reconsider with the user: Ctrl+S / Ctrl+R / Ctrl+P bindings, "Process YouTube's sound" on, the default crossfade,
  immersive background motion (~20 points of GPU).
- Music Detector needs a personal AudD token: friction for most users.
