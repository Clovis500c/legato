# Code of conduct

Legato is a small project and its issues, pull requests and discussions should stay pleasant for everyone.

- Be kind and stay on the subject: the software, not the person.
- Assume good faith. A bug report or a feature request is a gift of someone's time.
- No harassment, insults, discrimination or personal attacks, in any language.
- Do not share other people's private information.
- Keep issues to one problem each, and say which version you use.

The author may edit, hide or delete comments, and lock or close threads, that break these rules, and may block someone
who keeps breaking them. To report a problem with someone's behaviour, use a private report on GitHub (Security ›
Report a vulnerability) and say it is about conduct.
